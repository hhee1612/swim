# swim

游泳打卡网页：记录泳姿、距离、时间、心情和照片，查看日历、目标、勋章与统计。

## 本地运行

在仓库目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。也可直接部署到 GitHub Pages。页面依赖在线 React、Babel 和 Tailwind CDN，暂不支持完整离线使用。

## 记录和备份

- 同一天可记录多次：游泳次数按记录计数，打卡天数和勋章按日期去重。
- 距离和时间可以留空；平均配速仅汇总距离、时间均大于 0 的游泳记录，以总时间 / 总距离计算。
- 每条记录支持编辑、删除，以及当前页面中最近一次删除的撤销（含照片）。刷新页面后撤销入口不保留。
- 记录、照片、目标一起保存在当前浏览器的 IndexedDB 中；全部写入成功后才更新界面。数据不会自动同步到其他设备。
- 首次升级会校验并迁移旧版 localStorage 数据，保留旧数据作为迁移前副本。之后以 IndexedDB 为准，旧副本不再更新。
- 完整 JSON 备份可在新设备恢复；兼容旧版 v1 备份，导出使用 v2。导入前校验全部数据，格式错误或保存失败时保留当前数据。
- 如果旧数据损坏，会显示恢复入口，可导出旧版原始数据供排查；原始数据文件不是可直接导入的备份。
- CSV 用于表格查看，不含照片。文本中的引号、换行和 Excel 公式前缀会妥善处理。

建议定期导出完整 JSON 备份。清除浏览器网站数据、移除浏览器或更换设备不会自动保留记录。

## 验证

使用 Node.js 22 或更新版本：

```sh
node --test tests/core.test.cjs
```

核心逻辑在 `swim-core.js`，页面与交互在 `index.html`。
